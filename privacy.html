基本方針

本アプリは、氏名・メールアドレス・電話番号・位置情報・連絡先など、個人を特定できる情報を収集しません。アカウント登録はありません。広告配信・トラッキング目的の SDK は組み込んでいません。

匿名の利用者 ID

初回起動時に、端末内でランダムな利用者 ID を生成します。この ID は個人を特定できるものではなく、AI への質問回数の管理、購読状態の照合、利用状況の集計にのみ使います。

サーバーへ送信される情報

本アプリの一部の機能は、開発者が運用するサーバー（Cloudflare 上）と通信します。送信されるのは次の情報です。

  • 質問の内容：AI に質問すると、質問の本文と、読んでいる作品・位置の情報がサーバーへ送られます。サーバーは著者の原文を検索し、回答を生成するために質問と検索結果を Anthropic 社の API へ送信します。質問文そのものは記録に残しませんが、生成した回答本文（引用を含む）は、通信が途中で切れたときに同じ回答を取り直せるよう、匿名 ID と質問ごとの識別子に紐づけて 7 日間保存し、その後は本文を消去します（識別子の記録は 30 日で削除）。回答には質問の内容が反映されることがあります。このほか、匿名 ID・日時・対象の著者・利用量（トークン数）・応答時間・棄権や拒否の有無・アクセス元の国など、運用に必要な記録を保存します。
  • 利用状況のイベント：画面の到達、読了、購入画面の表示などの日ごとの件数を記録します（イベントに匿名 ID は含めません）。サービスの改善にのみ使います。
  • 購読状態：月額プランの購入・更新・解約は Apple が処理します。クレジットカード番号などの決済情報は開発者に渡りません。Apple のレシート情報は購読管理サービス RevenueCat が匿名 ID とともに検証し、購読の有無・商品・期間などの購読情報が開発者のサーバーへ通知・保存されます。

端末内にのみ保存される情報

読書位置、読了の記録、ノート、同意の状態は端末内に保存されます。本アプリをアンインストールすると削除されます。

誤りの報告・お問い合わせ

アプリ内の「報告」ボタンを押すと、お使いのメールアプリが開きます。送信するかどうかは利用者の操作によります。送信されたメールアドレスと本文は、報告への対応と内容の確認にのみ使い、他の目的には使いません。

国外での処理

本アプリは日本国内向けに提供しています。サーバー処理は Cloudflare、Anthropic、RevenueCat の各社の設備で行われ、日本国外で処理される場合があります。

保存期間と削除

匿名の利用記録は、品質と原価の把握のために保存します。記録の削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

子どものプライバシー

本アプリは 13 歳未満の子どもを対象としていません。

Privacy Policy (English)

Meicho Bandoku does not collect personally identifiable information and has no account registration, advertising, or tracking SDKs. On first launch the app generates a random anonymous user ID on the device, used only for question quotas, subscription status, and usage statistics. When you ask a question, the question text and the current reading position are sent to the developer's server (Cloudflare), which retrieves the author's original text and sends the question with the retrieved passages to Anthropic's API to generate an answer. Generated answers (including quotations) are stored with the anonymous ID for 7 days so that an interrupted response can be retrieved again, then the text is deleted (identifiers are deleted after 30 days); operational records (anonymous ID, timestamp, author, token usage, latency, country) are also kept. Purchases are processed by Apple; receipts are validated by RevenueCat together with the anonymous ID, and only the subscription status reaches the developer's server. Reading positions and notes are stored only on your device. Data may be processed outside Japan by the providers named above. For deletion requests, contact the address above.
